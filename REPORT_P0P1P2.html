核心结论：瓶颈不在 Sundial 预测器，而在下游概率的标度与 30min 窗的信息量。P0 校准修好了概率标度但造不出排序分离；P1 三款平替在测试期 AP 全部超过基线，但 maxp 仍压 ≈0.53；P2 用全部无标签波形做掩码重建预训练，把测试 maxp 首次拉到 0.656、测试 AP 提高 36%——信息瓶颈第一次被实质性打开。

方法任务设定与评估协议

两级架构

连续 DAS 波形 bin → 每 10 秒特征块 → 冻结 Sundial（30min 历史）预测未来特征走势 → 融合 6 维特征 → 9 参数离散时间风险模型（3 时窗截距 + 共享系数）→ P5 ≤ P10 ≤ P30。

数据

  • 连续特征：18285 个 10s 块（约 51 小时，含全部正常时段）；下游样本 4287 个（train 2963 / validation 615 / test 644），27 条岩爆标签、25 个记录组。
  • 时间划分（P0/P1/P2 共用）：train_end=2026-07-25T05:30:44.568+00:00，validation_end=2026-07-29T17:06:38.837500+00:00；按记录组时间顺序 70/15/15，边界剔除跨界标签。
  • 测试集仅 3 个可检事件，多方案共享测试集——所有结论属探索性。

P0 协议（P1/P2 共用）

ridge × l1_ratio × link（logit/cloglog）网格，按验证集 NLL 选参；选参后 Platt 校准（验证集拟合、冻结）；阈值三步协议（校准 → 验证集按召回≥0.4、孤立误报≤2 段选阈值 → 冻结 → 测试报数），无可行工作点则记录 no_operating_point 而非静默回退。

P0概率校准：修好标度，但造不出排序分离

做了什么

  • 前置：exp02 因果性修正（10s 特征块严格在预测时刻前完成）+ 记录组分组建模切分；exp03/04 瞬态特征消融（超阈值计数特征测试 AP +102%）；exp05 事件均衡训练（正负概率分离显著，验证 AP 0.314→0.499）。
  • exp06 自动阈值暴露问题：均衡模型 30min 概率压缩在 0.5 附近（全数据 max≈0.52），自动阈值只能选到全静默方案（no_operating_point）。
  • exp07（P0 本体）：_p0_calibration.py——Platt 校准（IRLS）+ cloglog/logit A/B + ridge×l1 网格，按验证 NLL 选参，三步阈值；_p0_selftest.py 数值自检。

P1预测器平替对照：换 Sundial 有效，但瓶颈不在它

做了什么

  • 三个 Apache-2.0 开源时序基础模型（chronos2：Amazon，TSMixer+稀疏 MoE；TiRex：微软 NX-AI，TSMixer 变体；Lag-Llama：Mila，Llama 解码器 + lags + Student-t）替换 Sundial 的 30min 预测环节。
  • 只替换「未来特征预测器」，下游 9 参数概率模型原样保留（每个预测器下按 P0 协议重训一次）；跳过索引与特征提取，复用 exp06 中间产物（6232 预测时刻 / 25 记录组 / 4287 样本）。
  • Lag-Llama 适配要点：past_len=1272（lag_pad+ctx）、future_time_feat 给满 187 步、单趟采样 use_single_pass_sampling=True（提速约 20 倍）、批量预填（BATCH=8）4258 条缓存落盘。

P2掩码重建预训练：用全部无标签波形抬信息上限

做了什么

  • 预训练：在 continuous.csv 全部 18285 个 10s 特征块（26 段、约 51 小时无标签波形，含全部正常时段）上训练 3 层 Transformer encoder（59.7 万参数，d=128）做掩码重建（80% 单点 + 20% 连续块掩码，MSE），50 epoch loss 7.33→1.66；特征取 8 维核心连续特征，log1p + z-score。
  • 表征：对每个下游样本取其预测时刻前 30min 历史窗口（严格因果），encoder mean-pool 得 128 维；在训练集上 PCA 降 8 维并 z-score，拼接进原 x 前 6 列（sundial / lagllama 两个特征源各一套，14 维）。
  • 微调：9 参数风险模型按 P0 协议重训（ridge×l1×link NLL 选参 + Platt + 三步阈值），同一时间划分。

结论 测试 maxp 首次突破 0.53 瓶颈：0.557 → P2 sundial 0.656（+18%）、lagllama 0.654、tirex 0.628；测试 AP：sundial 0.5098（较基线 +36%）、tirex 0.5587（P1 的 0.4909 再 +14%、较基线 +49%）、lagllama 0.5623（全程最高）；P2 lagllama 测试 NLL 0.6701 首次系统性低于 ln2≈0.693。表征增益跨三个预测器一致，且 tirex+表征验证召回保持 1.0（5/5 全检出）。P0/P1 都解不开的"概率挤中间"，被无标签波形学到的时序表征拉开了。
代价与未决 验证集孤立误报段普遍上升（sundial 5→16、lagllama 9→12、tirex 4→10）——概率拉开后更多窗口跨过 0.5，误报管理成为新焦点；测试 ECE 0.28 仍欠标定；预训练用全部无标签窗口（与报告口径一致，transductive），PCA/尺度统计只在训练集拟合。
阈值工作点扫描（重审 0.5） 细网格（0.02–0.98 步进 0.01）在验证集重扫三源 30min 决策阈值（min_active_bins=2），结论：0.5 是 no_operating_point 回退值而非设计值，但三源可工作区全部落在 0.46–0.51，它并非离谱；0.5 恰在"敏感度悬崖"上（sundial 阈值 0.49→0.50 孤立误报段 9→16，概率在 0.48–0.53 顶部扁平堆积，误报段数随阈值非单调）；trade-off 根因是验证窗口过短（10.25h 内 5 事件，报警时间占比 0.46–0.80），"孤立误报≤2 段"结构性不可满足；测试集三源 recall 均 0.33——测试 3 事件中 2 个概率无法被任何合理阈值捕获，属信息瓶颈。落地建议：固定 0.5 → 细网格 + 目标准则选点（预警推荐 cost5，或 tirex R80 点 t≈0.51：验证 4/5 召回、孤立误报 7 段、报警时间占比 0.460），并把判据改为业务代价 / 报警时间占比约束。
P2.5 阈值协议固化（model.py） select_operating_threshold 支持 legacy / cost / f1 准则 + miss_penalty + max_alarm_time_fraction，细网格仅显式传入 threshold_grid 时生效——向后兼容已验证：legacy 对照三源均复现 no_operating_point → 0.5 回退（与 P2 逐项一致）。三源四准则重训（experiment_10_p25，模型/校准与 P2 相同，只改阈值选择）： cost（5×漏检+误报段）选点与阈值扫描完全一致——sundial t=0.51（验证 5/5、isolFA 11、time 0.489）、lagllama t=0.46、tirex t=0.50（验证 5/5）； cost + 时间占比≤0.3 把阈值推到 0.53–0.57，验证 recall 降至 0.40（验证 maxp 仅 0.592，5 事件中仅 2 个峰值够高），但测试 recall 意外提升（lagllama 1.00、tirex 0.67）——测试事件峰值全部 ≥0.606； 重要发现：段起点匹配下 recall 非单调（sundial 测试 t=0.54 → 1/3、t=0.60 → 3/3），阈值越低报警段起点越早、可能落在 30min 窗口外造成漏检，"低阈值必不劣于高阈值"不成立，工作点须在目标网格上逐点核对。 生产建议：threshold_criterion="cost" + 显式细网格（预警语义）；时间占比约束待加长验证窗口后启用。

P12时序大模型预测集成（负面结论）

做了什么

  • 把 Sundial 与 P1 三源（chronos2 / tirex / lagllama）对同一目标序列的预测拼接（各源第 6 列 5/10/30min 预测均值），并可叠加「分歧」特征（各源预测极差 spread）；下游沿用 P0/P1 完全相同的协议（ridge×l1×link NLL 选参 + Platt 校准 + 阈值选择），重训 5 个变体（experiment_12_ensemble，N=4287，四源样本/标签逐项对齐）。
  • 变体：sundial_only（同协议基线 6 维）/ ens3（Sundial+TiRex+Lag-Llama 拼接 8 维）/ ens3_spread（+分歧极差 9 维）/ ens4（四源 9 维）/ ens4_spread（10 维）。
  • 本质：四源预测的是同一个 log1p(mean_square) 序列的走势——同构预测器，理论上只降方差、不补信息。

汇总P0/P1/P2 全方案纵向对比

测试集 30min AP 与最大概率；同一切分 + P0 协议；测试集 3 个可检事件，探索性。

验证/测试 NLL 越低越好；ln2≈0.693 是"对真实标签平均 50% 把握"的贴底线。

一句话主线

P0 修标度 → P1 证预测器可换 → P2 用无标签数据打开信息瓶颈；但三个阶段的共同尾巴是"阈值规则在 2 段误报约束下永远选不到工作点"，需要在放开约束或降误报之间二选一。

限制结果边界

  • 测试集只有 3 个可检事件，且多方案共享同一测试集——所有 AP/NLL 属探索性数字，不构成独立重复实验或已验证的现场性能。
  • 预训练使用全部无标签窗口（transductive），PCA 与尺度统计只在训练集拟合；下游协议严格保持训练/验证/测试分离。
  • P2 表征维度（PCA 8 维）与窗口长度（30min）未经系统搜索；更大 encoder / 更长窗口可能进一步提升，属超参探索空间。
  • 测试 ECE 偏高（0.28）与验证误报上升，说明表征拉开概率后校准与误报约束需要配套再调。
